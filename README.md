# 보미의 찰나 · ksana

스쳐 가는 생각을 체크인하듯 남기는 곳.

찰나(刹那)는 산스크리트어 **kṣaṇa(크샤나)**를 한자로 옮긴 말로, 아주 짧은 순간을 뜻해요.
날짜와 사건이 축이 되는 일기 대신, 생각 한 조각을 단위로 기록하고 나중에 다시 만나고 엮어서 아이디어로 키우는 저널이에요.

## 기능
- 열자마자 바로 쓰기, 쓰다 만 글 자동 임시 저장
- '○월 ○일 저녁의 찰나' 형식의 시간 표시 (날짜 제목 없음)
- 새 찰나를 남기면 닮은 옛 찰나를 보여주기 ("예전에도 이런 생각을 했어요")
- 이어 쓰기, 다른 찰나와 엮기, 닮은 찰나 추천
- #태그 묶기, 검색
- 링크 첨부: 글 속 링크는 눌러서 열리는 칩으로 표시, '🔗 링크' 버튼으로 복사한 링크 바로 붙이기
- 아이폰 홈 화면에 추가해 앱처럼 쓰기, 오프라인에서도 열림
- 백업 파일 내보내기·불러오기

## 저장
GitHub Pages 버전은 기기 브라우저(localStorage)에만 저장돼요. 기기 간 동기화는 아직 없어요.
